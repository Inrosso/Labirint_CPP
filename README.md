## 📖 Что это за игра?
**Лабиринт** — консольная игра-головоломка, где вы управляете символом `@`, ищете сокровище `$`, а затем выбираетесь через выход `E`.  
Игра поддерживает несколько уровней, историю ходов, подсказки и таблицу прохождений. Все структуры данных (стек, очередь, список) реализованы вручную без использования STL.

## 🎯 Как играть?
### Основная цель
1. Сначала **найти сокровище** (`$`) на карте.
2. Затем **добраться до выхода** (`E`), не наступая на стены.
3. Уровень пройден, только если сокровище уже собрано.

### Управление
* `W` / `A` / `S` / `D` — движение (вверх, влево, вниз, вправо)
* `Z` — **шаг назад** (отмена последнего хода)
* `H` — **подсказка** (показывает кратчайший путь к цели)
* `Q` — выход в главное меню

### Особенности уровня
* Счётчик шагов — чем меньше, тем лучше.
* После прохождения уровня предлагается перейти на следующий (случайный или увеличенного размера).
* Можно в любой момент вернуться в меню и начать новую игру.

## 🚀 Как запустить игру?
### Самый простой способ (для Windows)
1) Скачайте готовый исполняемый файл `Labirint_CPP.exe`.
2) Поместите его в отдельную папку.
3) Запустите двойным кликом — игра откроется в консоли.

### Если хотите собрать сами (Windows / Linux / macOS)
Нужен компилятор C++ с поддержкой C++11.

#### Клонируйте репозиторий и соберите:
```bash
git clone https://github.com/ваш-username/labirint-cpp.git
cd labirint-cpp
g++ -std=c++11 -o maze *.cpp
./Labirint_CPP          # Linux/macOS
Labirint_CPP.exe        # Windows
```

## 📁 Что внутри игры?
Вот из каких частей состоит программа:

```text
Labirint_CPP.cpp      # Точка входа, главное меню, маршрутизация
game.h / .cpp         # Логика игрового цикла, управление, отрисовка
maze.h / .cpp         # Лабиринт: загрузка, генерация, BFS, поиск пути
containers.h / .cpp   # Собственные структуры: стек (история), очередь (BFS), список рекордов
validator.h / .cpp    # Ввод с проверкой, очистка строк, валидация лабиринта
point.h               # Класс координат (строка, столбец)
console.h / .cpp      # Настройка кодировки, очистка экрана, пауза
exceptions.h          # Иерархия исключений
records.txt           # Файл с сохранёнными прохождениями (создаётся автоматически)
lab.txt               # Пример пользовательского лабиринта
```
